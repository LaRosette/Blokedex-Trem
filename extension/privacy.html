Blokedex-Trem · version 3.1

Votre fil, votre choix.

Deux onglets, une même liste : masquer les contenus dans votre navigateur, ou bloquer les comptes sur X. Aucune action ne démarre simplement en ouvrant l’extension.

Masquer dans ce navigateur

Le filtre repère les auteurs des publications et les cartes de profils. Il masque les contenus reconnus sans modifier votre compte X. Si un auteur non listé cite un compte sélectionné, son commentaire reste visible et seule la citation est masquée. Une mention ne suffit pas à masquer un post.

Les posts gardent leur hauteur afin d’éviter des chargements répétés du fil. Les profils directs sont couverts par un panneau avec un bouton de pause. Mettre le filtre en pause restaure l’affichage. Les médias masqués sont mis en pause, jamais relancés automatiquement.

Le compteur décrit les posts et citations masqués sur la page actuelle ; ce n’est pas un nombre de personnes ou de vues évitées. Le filtre n’envoie aucune action native « mute » ou « Pas intéressé ». X peut avoir chargé et comptabilisé le contenu avant son masquage. Ce réglage concerne le site web dans ce profil de navigateur, sans effet sur l’application mobile.

Bloquer sur votre compte X

Le bouton de blocage lance volontairement le traitement dans un seul onglet X réutilisé. Vous devez être connecté à X dans ce navigateur. Chaque utilisateur agit sur son propre compte. L’extension vérifie le pseudo et l’identifiant numérique des profils avant les clics ; elle s’arrête si l’identité ou la session change.

Arrêter interrompt les clics suivants. Une action déjà envoyée peut encore aboutir. Les blocages confirmés restent actifs sur X : ni la pause du filtre, ni l’effacement de l’historique, ni la désinstallation ne les annulent. Aucun déblocage n’est effectué par l’extension.

Les règles de X interdisent l’automatisation de son interface et prévoient une possible suspension, y compris permanente. Les contrôles et les pauses ne garantissent ni un comportement humain, ni un risque faible ou nul. Une limitation signalée par X entraîne au moins quinze minutes de pause, sans reprise automatique. Pour éviter les actions automatiques sur X, choisissez le filtrage local.

Lire les règles d’automatisation de X. Le projet est indépendant de X et ne garantit aucune baisse de portée des comptes de la liste.

Vos données restent locales

L’extension ne demande ni mot de passe, ni cookie, ni clé. Elle ne lit pas vos cookies ou vos jetons de connexion. Le blocage utilise les boutons de X dans votre session déjà ouverte.

La liste, vos réglages et les informations de mise à jour restent dans le stockage local de l’extension. Si vous lancez le blocage, la progression, le pseudo de votre compte, une empreinte dérivée de son avatar et les identifiants déjà traités sont conservés localement. Cet historique est séparé par compte, limité à cinq comptes et effaçable depuis l’onglet Bloquer. L’empreinte n’est pas une garantie d’anonymat.

Aucun serveur applicatif ne reçoit ces données. Aucun historique de lecture, texte de publication ou événement d’utilisation n’est envoyé. Il n’y a ni publicité ni télémétrie.

Les fichiers publics de liste et de version proviennent de GitHub, qui reçoit les informations réseau habituelles, dont votre adresse IP. Ces requêtes n’envoient ni identité X ni contenu de votre fil. Les JSON téléchargés contiennent des données, pas du code exécuté à distance. Les compteurs GitHub concernent les fichiers téléchargés, pas l’utilisation de l’extension.

La liste et les mises à jour

La liste incluse est vérifiée toutes les six heures lorsque le navigateur est ouvert. Les ajouts sont signalés dans l’extension et pris en compte par le filtre actif. Ils ne déclenchent jamais un blocage seuls : un nouveau lancement volontaire est nécessaire.

Le code d’une installation manuelle exige de remplacer les fichiers et de recharger l’extension, puis d’actualiser les pages X ouvertes. Une mise à jour de la liste ne remplace pas le logiciel. Firefox nécessite un paquet signé par Mozilla pour une installation permanente.

Une correction ou un retrait ?

La présence dans la liste est un choix éditorial et ne constitue pas une qualification des opinions ou affiliations du titulaire. Les pseudos et identifiants publics peuvent être des données personnelles ; leur contexte peut révéler des opinions politiques sensibles. Un titre neutre et le stockage local ne suffisent pas à garantir une conformité juridique ou RGPD. Le projet n’est pas certifié par la CNIL.

Pour demander un ajout, une correction, un retrait ou l’examen de vos droits, contactez @MEYTRED avec le lien du profil concerné. N’envoyez aucun mot de passe, cookie ou document d’identité dans une issue publique.
